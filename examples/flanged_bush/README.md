# Example: flanged bush

A turned bronze bush with a flange. It's generated by script, so the repo has no CAD files.

| File | Contents |
|---|---|
| `bush.params.yaml` | the part's dimensions |
| `make_part.py` | builds the part (revolve, with named dimensions and global variables) and a drawing with front and isometric views |
| `bush.edit.yaml` | an edit spec: the flange widened to 42 mm, with the expected volume, area and bounding box |
| `bush.drawing.yaml` | the drawing spec: section C, detail D, five self-checked dimensions, datums A and B, runout and perpendicularity frames, a chamfer note, notes block and title block |

```powershell
uv run python examples/flanged_bush/make_part.py --args "{\"out\": \"~/swdraw-example\"}"
uv run python -m swdraw build --spec examples/flanged_bush/bush.drawing.yaml
```

To try a part edit:

```powershell
uv run python -m swdraw model inspect --part ~/swdraw-example/ACME1-MEC-2101.SLDPRT
uv run python -m swdraw model edit --spec examples/flanged_bush/bush.edit.yaml          # check only
uv run python -m swdraw model edit --spec examples/flanged_bush/bush.edit.yaml --save   # back up, then save
```

The diameters are global variables (`flange_d`, `body_d`, `bore_d`) that drive the sketch radii
through equations. `length@Profile`, `flange_t@Profile` and `chamfer@Profile` are plain
dimensions. After a saved edit the drawing spec no longer matches the part, so update
`D_FLANGE` and the flange picks before rebuilding the drawing.

`tests/test_spec_and_example.py` checks every pick sits on the outline from `bush.params.yaml`, and
every `expect` matches the parameters. Change the parameters and you'll need to update the picks.

Section C is cut on the plane x = 0, so its geometry is at `(0, y, ±radius)`. The part axis is
model Y.
