# Example: flanged bush

A turned bronze bush with a flange, generated by script so the repository contains no CAD files.

| File | Contents |
|---|---|
| `bush.params.yaml` | the part's dimensions |
| `make_part.py` | builds the part (revolve) and a drawing with front and isometric views |
| `bush.drawing.yaml` | the drawing spec: section C, detail D, five self-checked dimensions, datums A and B, runout and perpendicularity frames, a chamfer note, notes block and title block |

```powershell
python examples/flanged_bush/make_part.py --args "{\"out\": \"~/swdraw-example\"}"
python -m swdraw build --spec examples/flanged_bush/bush.drawing.yaml
```

`tests/test_spec_and_example.py` checks that every pick in the spec lies on the part outline
defined by `bush.params.yaml`, and that each dimension's `expect` matches the parameters. If you
change the parameters, update the picks too.

The section is cut on the plane x = 0, so all geometry in section C is at `(0, y, ±radius)`
with the part axis along model Y.
