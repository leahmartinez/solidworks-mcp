# Example: flanged bush

A turned bronze bush with a flange. It's generated by script, so the repo has no CAD files.

| File | Contents |
|---|---|
| `bush.params.yaml` | the part's dimensions |
| `make_part.py` | builds the part (revolve) and a drawing with front and isometric views |
| `bush.drawing.yaml` | the drawing spec: section C, detail D, five self-checked dimensions, datums A and B, runout and perpendicularity frames, a chamfer note, notes block and title block |

```powershell
uv run python examples/flanged_bush/make_part.py --args "{\"out\": \"~/swdraw-example\"}"
uv run python -m swdraw build --spec examples/flanged_bush/bush.drawing.yaml
```

`tests/test_spec_and_example.py` checks every pick sits on the outline from `bush.params.yaml`, and
every `expect` matches the parameters. Change the parameters and you'll need to update the picks.

Section C is cut on the plane x = 0, so its geometry is at `(0, y, ±radius)`. The part axis is
model Y.
