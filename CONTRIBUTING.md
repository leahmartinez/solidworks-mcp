# Contributing

Issues and pull requests are welcome. Please:

- keep anything product-specific out of the core: geometry, numbers and text belong in specs and
  profiles
- add a test with `tests/fakes.py` for logic that can run without SolidWorks
- add new SolidWorks API surprises to `GOTCHAS.md`
- never commit native SolidWorks files (`.sldprt`, `.sldasm`, `.slddrw`, `.slddrt`, `.drwdot`,
  `.swp`) or PDFs/renders exported from a real installation; examples are generated by script

## What the tests cover, and what they can't

`python -m pytest` runs anywhere. It exercises, against a fake of the drawing API:

- selection: rejecting view-only picks, trying other entity kinds
- self-checked dimensions: expected values, alternative pick pairs, delete and regenerate on a
  mismatch, tolerance write and read-back, prefix, suffix and precision
- title-block matching by position and placeholder; revision rows, REV box, approval, "SEE NOTE n"
  in both title-block modes
- notes block numbering, replacement and de-duplication
- builder step selection, notes block and title block via custom properties
- folder tidy (merge identical, never clobber, lock files, folders), the register workbook (and
  its formulas when LibreOffice is installed), numbering, spec validation, the CLI and the MCP
  script-folder guard
- that every pick point in the example spec lies on the example part's outline

They can't check behaviour that only real SolidWorks shows:

- whether a pick at a given sheet point really hits the intended edge (depends on tessellation,
  view display mode and zoom)
- section/detail view creation, orientation and alignment
- `InsertGtol` / `InsertDatumTag2` through `IDispatch`, frame symbol codes
- text format changes, document defaults and their effect on the sheet format
- Save As ordering, file locks, reference re-pointing, `GetDocumentDependencies2`
- PDF export and the example's `make_part.py` (revolve feature arguments, template selection)

If you change any of those, run the flanged-bush example end to end on a real installation and
say which SolidWorks version you used in the pull request.
