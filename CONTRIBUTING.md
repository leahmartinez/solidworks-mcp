# Contributing

Issues and pull requests are welcome. Please:

- keep product-specific stuff (geometry, numbers, text) in specs and profiles, not the core
- add a test using `tests/fakes.py` for anything that can run without SolidWorks
- add new SolidWorks API surprises to `references/api-gotchas.md`
- after changing a tool in `mcp_server/server.py`, update `manifest.json` and run
  `uv run --extra mcp python scripts/generate_capabilities.py` (CI checks both)
- don't commit native SolidWorks files (`.sldprt`, `.sldasm`, `.slddrw`, `.slddrt`, `.drwdot`,
  `.swp`), or PDFs and renders from a real install. Examples are generated by script.

## What the tests cover

`uv run --extra dev python -m pytest` runs anywhere, against a fake drawing API. It covers:

- selection: rejecting view-only picks, trying other entity kinds
- self-checked dimensions: expected values, alternative pick pairs, delete and regenerate on a
  mismatch, tolerance write and read-back, prefix, suffix and precision
- title-block matching by position and placeholder; revision rows, REV box, approval and
  "SEE NOTE n" in both title-block modes
- notes block numbering, replacement and de-duplication
- builder step selection, notes block and title block via custom properties
- folder tidy (merge identical, never clobber, lock files, folders), the register workbook and its
  formulas (when LibreOffice is installed), numbering, spec validation, the CLI and the MCP
  script-folder guard
- every pick point in the example spec sitting on the example part's outline
- part edits against a fake part API whose equations evaluate on rebuild: globals, equations,
  dimensions (mm, degrees, units), configurations, design-table rows, read-back after the rebuild,
  equation-driven and read-only dimensions, rebuild errors, `expect` checks, revert, backup and
  save refusals, `inspect` and its spec stub
- the example edit spec's expected volume, area and bounding box against the bush geometry

## What they can't cover

Only real SolidWorks shows these:

- whether a pick at a sheet point hits the intended edge (depends on tessellation, display mode
  and zoom)
- section and detail view creation, orientation and alignment
- `InsertGtol` / `InsertDatumTag2` through `IDispatch`, frame symbol codes
- text format changes, document defaults and their effect on the sheet format
- Save As order, file locks, reference re-pointing, `GetDocumentDependencies2`
- PDF export and the example's `make_part.py` (revolve arguments, template selection, sketch
  relations, named dimensions and equations)
- part editing: `SetSystemValue3` with an empty configuration list, `GetType` values,
  `SetEquationAndConfigurationOption` and its configuration option, `GetErrorCode2`'s by-reference
  argument, design-table `SetEntryValue` and `UpdateTable`, `CreateMassProperty2`, `GetPartBox`,
  `MaterialIdName` and `Save3`

If you change any of these, run the flanged bush example end to end on a real install. Put the
SolidWorks version in the pull request.
